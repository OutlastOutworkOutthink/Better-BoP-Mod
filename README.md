# PolyEconomic Balance

A PolyMod data mod for The Battle of Polytopia.

## Current changes

- Regular Warrior maximum health increased to 15 HP (`150` in the game's
  internal stat scale).

## Install for development

Copy this project folder into the PolyMod mods directory, keeping
`manifest.json` and `patch.json` together at the top level of the mod folder.
Then enable the mod and restart the game.

This project currently uses a GameLogicData patch only; it does not require a
compiled PolyScript DLL.
